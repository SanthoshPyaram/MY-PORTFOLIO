## 🚀 How to Run Locally

### Prerequisites
- Node.js (v18+ or v20+ or v24+)
- npm (v9+)

### Installation & Development Server
```bash
# 1. Clone repository
git clone https://github.com/SanthoshPyaram/MY-PORTFOLIO.git
cd MY-PORTFOLIO

# 2. Install dependencies
npm install

# 3. Start development server
npm start
# or: ng serve
```
Navigate to `http://localhost:4200/` in your browser.

### Production Build
```bash
npm run build
# Compiled output will be generated in dist/my-portfolio/browser/
```
